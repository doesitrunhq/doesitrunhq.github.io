WordCraft

An open-source, clean-room reimplementation of Microsoft Word in pure Rust. Reads and writes .docx, runs on macOS, Windows, Linux, BSD and the web (WebAssembly), and has a CLI (wordcraft-cli) that converts docx to pdf, odt, rtf, html, md, tex, txt and png.

https://github.com/storytold/wordcraft

WordCraft's CLI built from source in about 7.5 minutes (Rust, no network needed after the build) and converted .docx files to PDF, Markdown, HTML, TXT and PNG correctly, including a table and accented/Japanese text. Bad input fails with a clear message and exit code 1. It is alpha software, so expect gaps.

Commands we ran

Everything ran in a disposable Docker container. Reproduce with:

git clone --depth 1 https://github.com/storytold/wordcraft && cd wordcraft && cargo build --release -p wordcraft-cli && ./target/release/wordcraft-cli run --template sample --cmd 'select.text={"text":"Membership"}' --cmd format.bold --save out.docx && ./target/release/wordcraft-cli convert out.docx out.pdf && ./target/release/wordcraft-cli convert out.docx out.md
Our own case used a small helper script that writes a minimal invoice .docx (heading, two-row table, accented and Japanese text) with Python's zipfile, then converts it to md, html, txt, pdf and png.
  1. Clone the repo passed
    git clone --depth 1 https://github.com/storytold/wordcraft.git repo && git rev-parse HEAD
  2. Audit build scripts and process spawning passed
    find build.rs; grep Command::new; grep deps
  3. Install Rust toolchain (rustup) passed
    curl https://sh.rustup.rs | sh -s -- -y --profile minimal
  4. Build wordcraft-cli in release mode passed
    cargo build --release -p wordcraft-cli
  5. README example: create, bold, convert to PDF and Markdown passed
    wordcraft-cli run --template sample --cmd 'select.text={"text":"Membership"}' --cmd format.bold --save out.docx; convert out.docx out.pdf; convert out.docx out.md
  6. Our case: hand-made invoice .docx with a table to five formats passed
    python3 mkdocx.py; wordcraft-cli convert invoice.docx invoice.{md,html,txt,pdf,png}; text; inspect
  7. Failure cases: missing file, corrupt docx, unknown extension passed
    wordcraft-cli convert nope.docx x.pdf; convert bad.docx bad.pdf; convert invoice.docx x.xyz
