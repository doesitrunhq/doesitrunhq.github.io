Commands we ran

Everything ran in a disposable Docker container. Reproduce with:

python pipeline/testar/sandbox.py iniciar vibex; docker exec hf-vibex bash -lc 'cd /work && git clone --depth 1 https://github.com/Raja0sama/vibex.git repo && cd repo && git checkout 95f4b3f15642bc9261314e53d3d1649a94f6e8e1 && node bin/vibex.mjs demo /work/out'  (Node 22, sem internet apos o clone)
  1. clone, commit e versao ok
    git clone --depth 1 https://github.com/Raja0sama/vibex.git repo && git rev-parse HEAD && node -p require('./package.json').version
  2. auditoria: scripts, dependencias, rede ok
    node -e (package.json scripts/deps); grep child_process|fetch|https.request|XMLHttpRequest|net.connect em bin importers renderers
  3. demo do README, sem internet ok
    node bin/vibex.mjs demo /work/out && ls /work/out | grep html
  4. caso nosso: schema Prisma proprio com 2 tabelas ok
    vibex import prisma schema.prisma meu.erd.json --title Blog && vibex render meu.erd.json meu.erd.html && ls -la meu.erd.html && grep -c Post meu.erd.html
  5. caso de falha: spec invalida ok
    echo '{"type":"erd"}' > ruim.json; vibex validate ruim.json; echo exit=$?
